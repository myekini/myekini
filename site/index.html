CostTrail cloud cost allocation

Can engineering and finance trace an allocated cost back to its source and see why it changed?

data
AWS billing data in FOCUS 1.4, modelled into billed and amortized cost.
rule
Shared cost is allocated to teams and totals are preserved to the cent.
llm
A variance explainer: the pipeline computes the change, the model explains it, code checks every number.

# every llm feature follows the same loop

  1. the pipeline computes the facts
  2. the llm explains or proposes
  3. code checks every number
  4. a human approves any change to data
  5. every step is logged
  6. a small evaluation set scores it
