# Portfolio v3 (Claude Design export)

The original design file, kept as reference. It is not deployed.

The live site is the hand-built version in [`/site`](../../site). It renders the same design as plain HTML, CSS and JavaScript, so it doesn't load React and Babel from a CDN on every visit.

To view this export, serve the folder and open `index.html` (it needs `support.js` and `image-slot.js` next to it).
